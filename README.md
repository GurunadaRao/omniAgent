# Omni-Agent

Omni-Agent is an AI-powered agent execution and planning framework.

## Folder Structure

- `apps/`: Houses the services (`api`, `planner-service`, `execution-service`, `report-service`).
- `packages/`: Contains internal libraries and shared configuration packages.
- `infrastructure/`: Infrastructure configurations (Docker, Kubernetes, Nginx, monitoring).
- `scripts/`: Development and automation scripts.
- `docs/`: System documentation.
