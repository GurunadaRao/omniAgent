# Contributing Guidelines

## Branching Model

- `main`: Production-ready code.
- `development`: Main integration branch.
- `feature/planner`: Features related to task planning.
- `feature/execution`: Features related to task execution.
- `feature/report`: Features related to report generation.

## Pull Requests

- Commit messages must be clear and descriptive.
- Always run tests and typechecks before submitting.
- Avoid introducing circular dependencies between packages or services.
