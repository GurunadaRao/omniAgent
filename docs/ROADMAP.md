# Project Roadmap

## Version 1: Core Automation (Current Phase)
- **Planner Service**: Converts requests into sequential task DAGs.
- **Worker Pools**: Introduces Web, Browser, GitHub, and LLM workers.
- **Report Generation**: Aggregates worker outputs to raw Markdown files.

## Version 2: Multi-Agent Reasoning
- **Task Refinement**: Real-time plan adjustment during execution.
- **Vision Models**: Support image processing and OCR crawling.
- **Multi-modal report generation**: HTML report dashboards.

## Version 3: Enterprise & Collaboration
- **Human Approval**: Integration points for manual execution steps.
- **Agent Memory**: Long-term memory storage via vector db databases.
- **Autonomous Execution**: Multi-agent scheduling and self-healing error recovery.
